# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集・**2027年カレンダー**・**🔞 アダルト・R18**の**発売日（今月〜3ヶ月先）**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホからワンタップでチェックできるモバイルファースト情報センターです。

- 🌐 **スマホ公開URL（GitHub Pages）**：https://kenandxx.github.io/happy-magazine-center/

## 主な機能（プロトタイプ v0.7）

- **🔥 新タブ「早め予約・争奪戦レーダー」(`#tab-urgent`)**：直近〜今後2〜3ヶ月（-14日〜+100日）を対象に、透明な7要素スコアリング（`src/scarcity-score.js`：直筆サイン本／3000・4000部限定豪華愛蔵版／ストア限定表紙／超人気タレント／推しワード連動／限定特典の種数／発売締切＆絵柄解禁スパイク）で **🔴 Sランク（即予約推奨）・🟠 Aランク（早め確保）・🟡 Bランク（注目枠）** を自動判定。「未予約のみ表示」トグル・理由バッジ・最優先ストアへの1タップ即予約ボタン・1タップ `✓ 予約済にする` で取り逃がしをゼロにします。
- **🔞「アダルト・R18」カテゴリを徹底調査・大幅拡充（10作品 → 39作品）**：彩文館出版の豪華愛蔵版3000/4000部限定（小野六花・初美なのか・木村愛心・彩月七緒）、徳間書店・竹書房・双葉社・ジーウォーク・ジーオーティーの最新ヘアヌード写真集（伊藤舞雪・園梨音・小島みなみ・宮下玲奈・三澄寧々・弥生みづき・三好佑香・真木今日子・木下凛々子・川上ゆう・吉根ゆりあ・糸井瑠花・紺野栞 等）、プレミアムヌードポーズブック、人気女優の2027年壁掛け＆卓上カレンダー（河北彩伽・三上悠亜・瀧本雫葉・長浜みつり・波多野結衣・虹村ゆみ・宮下玲奈・八掛うみ・森日向子 等）、月刊FANZA・BACHELORまで実在ISBN/JAN・公式書影で徹底網羅。ヘッダーの **🚃 電車モード** で全タブ一括ぼかし対応。
- **🏷 表紙・特典エディション単位のステータス管理**：同じ雑誌でセブンネット等に複数の限定表紙・ポストカード版がある場合でも、**特定の表紙・特典（Offer）ごと**に「🤔 検討中」「👀 買う予定」「🛒 予約済」「✅ 購入済」「🙅 買わない」を個別管理。
- **🛡️ 写真整合性ガード＆徹底検査済み書影**：全163枚の画像URLを実機検証し、Amazon通常版へのセブンネット特典流用・旧号表紙・403/404・HMV「NO IMAGE」プレースホルダーを自動検出・除外する `scripts/validate-catalog.mjs` を組み込みました。
- **🔓 特典絵柄解禁ウォッチ / 💰 月別「推し活予算メーター」 / 📅 一括 `.ics` 出力 / 🤖 GitHub Actions 毎朝07:00 JST 自動更新**
- **🏪 ノイズゼロの購入先表示（Amazon基本＋特典付きストアのみ）**：Amazonを基本ストアとして常に表示し、セブンネット・楽天ブックス・HMV・TSUTAYAは確認済みのストア限定特典が付く場合のみ表示（非Amazon無特典 0件）。

## 構成

- `index.html` / `manifest.json` / `assets/icon.svg`：モバイルファースト・5タブナビ・PWA対応エントリーポイント
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（2列写真グリッド・早め予約レーダー・ワンタップビューア・版別ステータスUI・予算メーター・R18電車モードぼかし）
- `src/app.js` / `src/scarcity-score.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・売り切れ警戒スコアリングエンジン・版別棚管理・5ストア検索URL・公式SNS＆宣伝投稿リンク・単体＆一括 `.ics` 生成
- `data/catalog.json`：2026年9月〜2027年2月の実在 **107作品**（うち `🔞 R18` **39作品**）・**227オファー**（非Amazon無特典 0件）・実機検証済み画像163枚
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/validate-catalog.mjs`：ストアポリシー・画像整合性・HMV NO-IMAGE／403／404検出バリデータ
- `scripts/fetch-catalog.mjs`：毎朝自動更新パイプライン（公開RSS＋任意Rakuten Books API＋検証ガード）
- `.github/workflows/daily-catalog-update.yml`：毎朝07:00 JST自動更新＋手動実行（`workflow_dispatch`）ワークフロー
