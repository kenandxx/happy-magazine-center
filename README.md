# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集・**2027年カレンダー**・**🔞 アダルト・R18**の**発売日（今月〜3ヶ月先）**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホからワンタップでチェックできるモバイルファースト情報センターです。

- 🌐 **スマホ公開URL（GitHub Pages）**：https://kenandxx.github.io/happy-magazine-center/

## 主な機能（プロトタイプ v0.9）

- **🤖 15出版社 PR TIMES 公式RSS 毎朝07:00自動巡回＆新刊自動登録（`🆕 自動発見` バッジ付き）**：東京ニュース通信社・宝島社・講談社・KADOKAWA・小学館・光文社・双葉社・徳間書店・ワン・パブリッシング・秋田書店・イマジカインフォス・竹書房・ワニブックス・集英社・扶桑社の15出版社の公式プレスリリースを毎朝自動巡回し、アイドル・グラビア・写真集・2027カレンダー・R18の新刊と限定特典を自動抽出して `data/catalog.json` と「🔥 早め予約レーダー」へ自動投入します。
- **⚡ スマホ直結「Amazon URL / ISBN → openBD 1タップ自動取込＆早め予約スコア即判定」**：Amazonで見つけた本（例：松井珠理奈『アイヲシル』等）の商品URL（`/dp/...`）やISBNを貼り付けるだけで、ブラウザから直接日本の公開書誌DB（`api.openbd.jp`）を照会し、**公式書影・発売日・定価**を取得＆その場で **売り切れ警戒スコア（S/A/B）をライブ判定** してダッシュボードへ即投入できます。全端末カタログへの **📮 1タップGitHub収録リクエスト** も搭載。
- **📚 実在127作品・262オファー・検証済み書影187枚（うち `🔞 R18` 39作品・`🆕 自動発見` 20作品）**：松井珠理奈 2nd写真集『アイヲシル』、兒玉遥 3rd写真集『You will see』、高崎かなみ 3rd写真集、芳根京子 2027カレンダー、桃月なしこ・乃木坂46井上和 表紙号など最新20作品を追加収録。全187枚の画像をライブHTTP200・実体検証済み。
- **💖 推しコーナー＆1タップ人気タレント登録（80名超）＋👑 マイVIP超人気枠 (+30pt)＋🚀 3段階推し加点ブースト**：ボトムナビ「💖 推し・棚」からアイドル・グラビア・R18女優をタップするだけで推し登録＆VIP昇格。「💖 推しのみ」「🆕 自動発見」トグルで一覧を瞬時絞り込み可能。
- **🔥「早め予約・争奪戦レーダー」(`#tab-urgent`)**：直近〜今後2〜3ヶ月（-14日〜+100日）を透明な7要素スコアリング（`src/scarcity-score.js`）で **🔴 Sランク（即予約推奨）・🟠 Aランク（早め確保）・🟡 Bランク（注目枠）** に自動判定。
- **👈 左手ワンハンド最適化・🏷 表紙・特典別マーク棚・🛡️ 書影整合性ガード・💰 月別予算メーター・📅 一括 `.ics` 出力・💾 JSONバックアップ復元・🚃 R18電車モード・🏪 ノイズゼロ表示（非Amazon無特典 0件）**

## 網羅度をさらに100%に近づける任意設定（無料）

GitHubリポジトリの **Settings → Secrets and variables → Actions** に無料の楽天ウェブサービスアプリID（`RAKUTEN_APP_ID`）を1つ登録すると、毎朝07:00の自動更新パイプライン（`scripts/fetch-catalog.mjs`）が15出版社PR TIMESに加えて **楽天ブックスの写真集（`001013001`）・R18（`001014`）・主要雑誌の全限定特典＆新刊** も自動収集します（未設定のままでも15出版社PR TIMES＋openBDが完全動作します）。

## 構成

- `index.html` / `manifest.json` / `assets/icon.svg`：モバイルファースト・5タブナビ・PWA対応エントリーポイント
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（左手親指操作対応・2列写真グリッド・早め予約レーダー・openBD自動取込UI・ワンタップビューア・R18電車モードぼかし）
- `src/app.js` / `src/scarcity-score.js` / `src/isbn-lookup.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・売り切れ警戒スコアリング・openBDライブ照会・版別棚管理・5ストア検索URL・公式SNSリンク・単体＆一括 `.ics` 生成
- `data/catalog.json`：2025年9月〜2027年2月の実在 **127作品**（うち `🔞 R18` **39作品**・`🆕 自動発見` **20作品**）・**262オファー**（非Amazon無特典 0件）・実機検証済み画像187枚
- `scripts/prtimes-ingestor.mjs`：15出版社PR TIMES RSS精密フィルタ＆記事HTMLメタデータ／限定特典抽出エンジン
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/validate-catalog.mjs`：ストアポリシー・画像整合性・HMV NO-IMAGE／403／404検出バリデータ
- `scripts/fetch-catalog.mjs`：毎朝自動更新パイプライン（15出版社PR TIMES自動発見＋任意Rakuten Books API＋検証ガード）
- `.github/workflows/daily-catalog-update.yml`：毎朝07:00 JST自動更新＋手動実行（`workflow_dispatch`）ワークフロー
