# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集・**2027年カレンダー**の**発売日（今月〜3ヶ月先）**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホからワンタップでチェックできるモバイルファースト情報センターです。

- 🌐 **スマホ公開URL（GitHub Pages）**：https://kenandxx.github.io/happy-magazine-center/

## 主な機能（プロトタイプ v0.5）

- **🔍 ワンタップ写真＆特典確認ビューア（スワイプ＆直接購入対応）**：各カードの **🔍 確認** ボタンや詳細画面の表紙タップから、表紙・全ストア特典・先行カットをフルスクリーンで一括確認。ビューア内で**店舗バッジ・Amazon価格差・直接購入ボタン・ワンタップステータス登録**まで完結するため、販売ホームページへ移動せずに判断できます。
- **🏷 6段階マークコーナー＆クイック仕分け**：全作品の右上マークから1タップで **「🤔 検討中」「👀 買う予定」「🛒 7net予約済」「🛍 他店予約済」「✅ 購入済」「🙅 買わない」** を登録。「買わない」は自動で薄く表示＆ワンタップ非表示に対応し、**マーク・棚タブ**ではステータス別の件数パネルと購入予定／検討中の予算合計を一覧管理できます。
- **🗓 新ジャンル「2027年カレンダー」追加**：小栗有以・江籠裕奈・沢口愛華・長濱ねる・古畑奈和・和内璃乃・谷田ラナ・田中美久・山田あい・桜井日奈子など実在10作品（セブンネット・楽天・HMV限定特典含む）を追加収録。
- **🎉 これから3ヶ月のお楽しみコーナー（11月 → 12月 → 1月 → 2月）**：あなたの「次のお楽しみ」カウントダウンバナー＋月別ロードマップ（冊数・特典数・月間予算）＋**📅 スマホカレンダー登録（`.ics`出力・前日リマインダー付き）**を搭載。
- **⊞ 写真グリッド ＆ 📋 詳細 ＆ 📸 全写真ウォール ＋ 🎁 特典横並び比較（1秒要点まとめ付き）**。
- **🏪 ノイズゼロの購入先表示（Amazon基本＋特典付きストアのみ）**：Amazonを常に基本ストアとして表示し、セブンネット・楽天ブックス・HMV・TSUTAYAは**確認済みのストア限定特典が付く場合のみ表示**（非Amazon無特典 0件）。
- **📰 アカウント不要の公式先行カット＆SNS巡回ハブ**：ログイン不要で出版社公式プレスリリース・雑誌公式SNS・カバーガール宣伝検索へアクセス。

## 構成

- `index.html` / `manifest.json` / `assets/icon.svg`：モバイルファースト・PWA対応エントリーポイント（「ホーム画面に追加」対応）
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（2列写真グリッド・ワンタップビューア・マークピッカー・3ヶ月ロードマップ・横並び特典比較）
- `src/app.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・5ストア検索URL・公式SNS＆宣伝投稿リンク・`.ics`カレンダー生成
- `data/catalog.json`：2026年10月〜2027年2月の実在 **68作品**（アイドル専門誌13・グラビアムック12・週刊＆青年コミック誌12・女性誌アイドル表紙4・写真集17・2027カレンダー10）・**177オファー**（ストア限定特典114件 / 非Amazon無特典0件）・関連写真101枚・公式先行カット記事53件
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/media-collector.mjs`：アカウント不要の公開HTML/RSSから先行写真・ストアURL・公式SNSを自動抽出するメディア収集エンジン
