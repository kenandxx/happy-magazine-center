# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集の**発売日**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホから一括チェックできるモバイルファースト情報センターです。

## 主な機能（プロトタイプ v0.4）

- **⊞ コンパクト写真グリッド（初期表示）＆ 📋 詳細カード ＆ 📸 全写真ウォール**：スマホ1画面に4〜6冊の表紙が大きく並ぶ2列写真重視レイアウトを標準採用。用途に応じて詳細リストや全関連写真ウォールへ1タップ切替可能。
- **🎁 特典絵柄・店舗 横並び比較（↔ 横比較 / ⊞ 2列比較）**：同じ雑誌のポストカードA/B/Cや店舗別特典を絵柄サムネイル・**Amazon価格差バッジ（同価格 / Amazon比 +¥140）**・購入ボタン付きで横並び比較。絵柄タップでそのままライトボックス拡大可能。
- **📰 公式先行カット特集＆📱 アカウント不要SNSオフショット巡回**：ログイン情報を一切渡さずに、出版社公式プレスリリース（PR TIMES / B.L.T.web / MANGA Watch / ほんのひきだし / ORICON / 音楽ナタリー等）や雑誌公式X/Instagram、カバーガール本人の宣伝・オフショット検索へ1タップアクセス。
- **🏪 ノイズゼロの購入先表示（Amazon基本＋特典付きストアのみ）**：普段のポイント用ベースストアとして Amazon を常に表示しつつ、セブンネット・楽天ブックス・HMV&BOOKS・TSUTAYA などの他ストアは**確認済みのストア限定特典が付く場合のみ表示**します。
- **📅 発売カレンダー＆カウントダウン / 🔥 推しワード / ⚡ 特典発掘ハブ**。

## 構成

- `index.html` / `manifest.json`：モバイルファースト・PWA対応エントリーポイント
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（2列写真グリッド・横並び特典比較・ライトボックス対応）
- `src/app.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・5ストア検索URL・公式SNS＆宣伝投稿リンク生成
- `data/catalog.json`：2026年10月〜2027年1月の実在45作品（アイドル専門誌6・グラビアムック12・週刊＆青年コミック誌12・女性誌アイドル表紙4・写真集11）・137オファー（非Amazon無特典0件）・関連写真84枚・公式先行カット記事36件
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/media-collector.mjs`：アカウント不要の公開HTML/RSSから先行写真・ストアURL・公式SNSを自動抽出するメディア収集エンジン

## スマホで本物の写真をすべて見る方法（GitHub Pages）

1. 本リポジトリを GitHub へプッシュし、**Settings → Pages** で Source を `main` ブランチの `/ (root)` に設定
2. 発行されたURLをスマホの Safari / Chrome で開くと、セブンネット・PR TIMES・ORICON・楽天ブックス・蔦屋書店などの公開画像がそのままフル表示されます（「ホーム画面に追加」対応）
