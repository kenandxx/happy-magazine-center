# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集・**2027年カレンダー**・**🔞 アダルト・R18**の**発売日（今月〜3ヶ月先）**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホからワンタップでチェックできるモバイルファースト情報センターです。

- 🌐 **スマホ公開URL（GitHub Pages）**：https://kenandxx.github.io/happy-magazine-center/

## 主な機能（プロトタイプ v0.6）

- **🏷 表紙・特典エディション単位のステータス管理**：同じ雑誌でセブンネット等に複数の限定表紙・ポストカード版がある場合でも、**特定の表紙・特典（Offer）ごと**に「🤔 検討中」「👀 買う予定」「🛒 予約済」「✅ 購入済」「🙅 買わない」を個別管理。横並び比較カード・クイックステータス選択シート・拡大ビューア・マーク棚タブすべてがエディション単位で連動し、どの表紙特典を買ったか一目で分かります。
- **🛡️ 写真整合性ガード＆徹底検査済み書影**：全136枚の画像URLを実機検証し、Amazon通常版へのセブンネット特典流用・旧号表紙・403/404・HMV「NO IMAGE」プレースホルダーを自動検出・除外する `scripts/validate-catalog.mjs` を組み込みました。
- **🔞 新ジャンル「アダルト・R18」＆ `🚃 電車モード`（R18ぼかし）**：双葉社・竹書房・徳間書店・ジーオーティー・ハゴロモ等の商業R18写真集・2027カレンダー・月刊FANZA（10作品）を追加。ヘッダーの1タップ **🚃 電車モード** でR18サムネイルだけをぼかして外出先でも安心してチェックできます。
- **🔓 特典絵柄解禁ウォッチ**：`✨ 特典絵柄公開済` / `⏳ 絵柄・表紙解禁待ち` のワンタップ絞り込みと、解禁待ち作品のストア＆X速報ワンタップ確認バーを搭載。
- **💰 月別「推し活予算メーター」**：11月〜2027年2月の月ごとに設定予算（初期値 ¥15,000・プリセット＆自由入力対応）に対する「確定・予定（版別価格の正確集計）」と「検討中」を積み上げバーで可視化。
- **📅 一括スマホカレンダー登録（`.ics`出力）**：作品単体だけでなく、予定・予約済みの全エディションを1ファイルにまとめてスマホカレンダーへ一括登録（前日リマインダー付き）。
- **🤖 GitHub Actions 毎朝07:00 JST 自動更新**：`.github/workflows/daily-catalog-update.yml` により、毎朝07:00 JSTにログイン不要の公開RSS（PR TIMES等）および任意設定の楽天ブックスAPIをチェックし、ポリシー＆画像検証を通過した更新のみ自動反映します。
- **🏪 ノイズゼロの購入先表示（Amazon基本＋特典付きストアのみ）**：Amazonを基本ストアとして常に表示し、セブンネット・楽天ブックス・HMV・TSUTAYAは確認済みのストア限定特典が付く場合のみ表示（非Amazon無特典 0件）。

## 構成

- `index.html` / `manifest.json` / `assets/icon.svg`：モバイルファースト・PWA対応エントリーポイント
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（2列写真グリッド・ワンタップビューア・版別ステータスUI・予算メーター・R18電車モードぼかし）
- `src/app.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・版別棚管理・5ストア検索URL・公式SNS＆宣伝投稿リンク・単体＆一括 `.ics` 生成
- `data/catalog.json`：2026年10月〜2027年2月の実在 **78作品**・**190オファー**（非Amazon無特典 0件）・検証済み画像136枚
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/validate-catalog.mjs`：ストアポリシー・画像整合性・HMV NO-IMAGE／403／404検出バリデータ
- `scripts/fetch-catalog.mjs`：毎朝自動更新パイプライン（公開RSS＋任意Rakuten Books API＋検証ガード）
- `.github/workflows/daily-catalog-update.yml`：毎朝07:00 JST自動更新＋手動実行（`workflow_dispatch`）ワークフロー
