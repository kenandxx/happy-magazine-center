# Happy Magazine Center

日本のアイドル専門誌・グラビアムック・週刊誌＆青年コミック誌（ポスター／クリアファイル／DVD付録あり）・アイドル表紙の女性誌・写真集・**2027年カレンダー**・**🔞 アダルト・R18**の**発売日（今月〜3ヶ月先）**、**関連写真（表紙・限定表紙・特典絵柄・公式先行カット）**、**ストア別限定特典（セブンネット / 楽天ブックス / HMV&BOOKS / TSUTAYA / Amazon）**、**公式SNS＆カバーガール宣伝ポスト**をスマホからワンタップでチェックできるモバイルファースト情報センターです。

- 🌐 **スマホ公開URL（GitHub Pages）**：https://kenandxx.github.io/happy-magazine-center/

## 主な機能（プロトタイプ v0.8）

- **💖 推しコーナー復権＆1タップ人気タレント登録（アイドル・グラビア・🔞R18女優 70名超）**：ボトムナビ「💖 推し・棚」のトップに専用コーナーを配置。人気アイドル・グラビア・R18女優の名前をタップするだけで即「💖 推し登録」、右端の **👑** で自分専用の **Sランク超人気VIP枠（+30pt）** へ自在に昇格できます。作品詳細シートからも表紙タレントをその場で1タップ登録可能。
- **🚀 推しワード連動ブースト3段階調整＆「💖 推しのみ」横断フィルター**：「標準 +14pt」「**強め・推奨 +24pt**（デフォルト）」「推し最優先 +34pt」を1タップ切替でき、一覧タブでは「💖 推しのみ」トグルで自分の推し作品だけを瞬時に抽出できます。
- **🔥「早め予約・争奪戦レーダー」(`#tab-urgent`)**：直近〜今後2〜3ヶ月（-14日〜+100日）を対象に、透明な7要素スコアリング（`src/scarcity-score.js`：直筆サイン本／3000・4000部限定豪華愛蔵版／ストア限定表紙／マイVIP超人気枠／推しワード連動ブースト／限定特典の種数／発売締切＆絵柄解禁スパイク）で **🔴 Sランク（即予約推奨）・🟠 Aランク（早め確保）・🟡 Bランク（注目枠）** を自動判定。
- **🔞「アダルト・R18」39作品（全107作品・227オファー）＆ `🚃 電車モード`**：豪華愛蔵版3000/4000部限定・最新ヘアヌード写真集・ポーズ集・2027カレンダー・専門誌まで実在ISBN/JAN・検証済み書影163枚で徹底網羅。
- **💾 設定＆マイ棚のJSONバックアップ／スマホ引き継ぎ**：ログイン不要の端末内保存データを1タップで `.json` 保存・復元でき、機種変更や履歴クリア時も推しリスト・VIP枠・版別マーク棚を安全に引き継げます。
- **🏷 表紙・特典エディション単位のステータス管理 / 🛡️ 書影整合性ガード / 💰 月別推し活予算メーター / 📅 一括 `.ics` 出力 / 🤖 毎朝07:00 JST 自動更新 / 🏪 ノイズゼロ表示（非Amazon無特典 0件）**

## 構成

- `index.html` / `manifest.json` / `assets/icon.svg`：モバイルファースト・5タブナビ・PWA対応エントリーポイント
- `styles/main.css`：エディトリアル調 Vanilla CSS デザインシステム（2列写真グリッド・早め予約レーダー・ワンタップビューア・版別ステータスUI・予算メーター・R18電車モードぼかし）
- `src/app.js` / `src/scarcity-score.js` / `src/cover-art.js` / `src/store-links.js` / `src/social-links.js`：ダッシュボードUI・売り切れ警戒スコアリングエンジン・版別棚管理・5ストア検索URL・公式SNS＆宣伝投稿リンク・単体＆一括 `.ics` 生成
- `data/catalog.json`：2026年9月〜2027年2月の実在 **107作品**（うち `🔞 R18` **39作品**）・**227オファー**（非Amazon無特典 0件）・実機検証済み画像163枚
- `scripts/normalizer.mjs`：複数ストア表記揺れの同一号グルーピング・特典種別抽出・非Amazon無特典除外フィルター
- `scripts/validate-catalog.mjs`：ストアポリシー・画像整合性・HMV NO-IMAGE／403／404検出バリデータ
- `scripts/fetch-catalog.mjs`：毎朝自動更新パイプライン（公開RSS＋任意Rakuten Books API＋検証ガード）
- `.github/workflows/daily-catalog-update.yml`：毎朝07:00 JST自動更新＋手動実行（`workflow_dispatch`）ワークフロー
